# V20.1 — Jarvis Autonomous Autopilot

V20.1 extends the V20 Orchestrator into a practical goal-to-execution workflow while preserving the existing tool/approval boundary.

## Added
- Capability-aware Goal → Plan → Tasks planning.
- Automatic target detection for Email Agent, AI Workforce, and Outbound AI.
- Workspace registry with Windows defaults and Docker `/host-files` path translation.
- Read-only autonomous reason/inspect/workspace-inspect/verify execution.
- Existing confirmation tickets remain the gate for sensitive execution.
- `/v1/orchestrator/targets` for configured project targets.
- `/v1/orchestrator/autopilot` to create and immediately run a project.
- Verification can block a project when the worker reports `VERIFIED: NO`.
- Persistent task capability metadata with migration for existing V20 databases.
- Dedicated regression tests for target detection, workflow construction, and persistence.

## Example
`POST /v1/orchestrator/autopilot` with:

```json
{
  "goal": "Get Email Agent ready for production",
  "max_steps": 12,
  "model": "auto",
  "assistant_profile": "general"
}
```

Jarvis will inspect first, prepare a plan, execute only through the existing agent/tool authority, pause for exact sensitive-action approval, and verify afterward.

## Configuration
- `JARVIS_EMAIL_AGENT_PATH`
- `JARVIS_AI_WORKFORCE_PATH`
- `JARVIS_OUTBOUND_AI_PATH`

No API keys are changed by this release.
