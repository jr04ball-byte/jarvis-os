# Jarvis V18.2.1 — Adaptive Voice Fix

V18.2.1 tightens the V18.2 voice path without changing the V18.1 brain/tool architecture.

## Fixed
- Deepgram TTS now has a streaming PCM endpoint using `linear16`, 24 kHz, `container=none`; the browser consumes audio chunks incrementally instead of waiting for a complete WAV blob. Deepgram documents raw linear16/no-container output for streaming and REST streaming.
- Browser playback uses Web Audio PCM scheduling and cancels scheduled sources during barge-in.
- Barge-in now requires two consecutive above-threshold frames, reducing one-frame spikes and TTS echo false positives.
- Dashboard barge-in level handling no longer double-applies the noise-floor offset.
- Local Whisper fallback remains intact.

## Validation
- `voice-engine.test.js`: 19/19 passed.
- Python syntax compilation: passed.
- Browser inline JavaScript syntax checks: passed.
- Real microphone/Deepgram/speaker testing still required before declaring voice-to-voice production-ready.
