# Jarvis V18.1 — Routing Gap Fix

V18.1 keeps the V18 natural voice-to-voice experience and closes the routing
gap found in the V18 acceptance audit: deep distributed-systems prompts such
as "compare Raft with Paxos" were resolved to the fast model.

## Routing fix
- `_DEEP_HINTS` gains specific high-signal distributed-systems concepts:
  `consensus`, `raft`, `paxos`, `quorum`, `replicat*`, `leader election`,
  `fault toleran*`, `distributed systems/databases/computing/architecture/
  consensus`, `database architecture`, `consistenc*`.
- Generic words (`system`, `database`, `compare`, `explain`, `technical`)
  alone still route to the fast model.
- `select_model` now ignores `system`-role messages itself, so injected
  system prompts can never force deep routing regardless of caller.
  The chat-completions call-site filter is preserved unchanged.

## Preserved
- Fast conversation → Gemma 3 4B; coding/deep reasoning → Qwen 3.5 9B.
- Agent/tool operations → tool-capable model (Gemma lacks Ollama tools).
- Graceful tool-error results, adaptive compute, one-model GPU policy.

## Tests
- `tests/test_routing_v181.py`: joke/arithmetic → fast; Raft/Paxos and
  quorum/leader-election → deep; generic-word guards; system-injection
  guard; explicit-override/sales/agent rules preserved.
- `tests/test_v18_voice.py`: version assertion updated to `18.1.0`.
