# Jarvis V22.2 — Autopilot Integration & Environment-Aware Self-Correction

V22.2 connects the self-correcting Project Worker directly into Jarvis Autopilot and improves verification quality.

## Added

- Project health/readiness evidence before OpenCode edits a repository.
- Environment-vs-code failure classification so missing runtimes, permissions, or network failures do not waste coding repair attempts.
- Targeted JavaScript/TypeScript test selection for Jest/Vitest/Mocha-style repositories.
- `/v1/project-worker/health` endpoint.
- Autopilot execute tasks now invoke the bounded self-correcting worker instead of a one-shot OpenCode pass.
- Autopilot blocks with evidence when the worker cannot verify instead of continuing as though implementation succeeded.
- API version bumped to `22.2.0`.

## Safety model

Jarvis still owns authority. OpenCode is scoped to a registered workspace and may not modify secrets, deploy, publish, reset Git history, create commits, or perform external side effects. Verification remains independent of the coding worker.
