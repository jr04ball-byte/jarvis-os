# Jarvis V18.2 — Adaptive Voice-to-Voice

V18.2 makes continuous conversational voice the primary experience, built on
the V18.1 smart router. No routing, tool-safety, compute, or Model Lab
changes except the additive voice-turn endpoint below.

## Unified adaptive voice engine (`api-gateway/voice-engine.js`)
Shared, DOM-free logic used by the dashboard and the voice console:
- State machine `off → listening → thinking → speaking → listening`
  (illegal transitions refused; error recovers to listening).
- Provider selection: Deepgram when configured, local Whisper otherwise,
  automatic degradation after repeated Deepgram failures, privacy mode
  forces local-only (no cloud audio at all).
- Barge-in guard with noise-floor-relative threshold and cooldown, so TTS
  echo cannot retrigger interruptions.
- Incremental sentence buffer: streamed LLM tokens become speakable
  sentences immediately; the full response is never awaited.
- Submit guard (one in-flight turn), speech generations (stale TTS can
  never overlap a new turn), bounded turn history, silence-based local
  end-of-turn detection, TTS text cleanup.

## Voice turn endpoint (`POST /v1/voice/turn`)
- Tool-intent speech (TV, Gmail, calendar, play, reminders, …) and the
  sales profile run the tool-capable agent as JSON (Qwen).
- Everything else streams auto-routed chat as SSE with `X-Voice-Model`
  headers, so TTS starts on the first sentence (Gemma for conversation,
  Qwen for deep content via the unchanged V18.1 router).
- Conversation persistence, profile checks, and context trim mirror the
  chat endpoint; rate-limited like the other voice routes.

## Pages
- `voice.html`: rewritten onto the engine — continuous loop on both
  providers, barge-in everywhere, Deepgram→local auto-fallback, privacy
  toggle, typed fallback kept, no navigation.
- `dashboard.html`: voice panel keeps its UX; speech is now sentence-
  streamed, barge-in uses the shared guard, Deepgram connect/disconnect
  failures fall back to local voice automatically, new Private toggle.

- `tests/test_voice_turn.py`: path selection, endpoint/route wiring,

- Routing A–F and V18 voice assertions re-run unchanged.
