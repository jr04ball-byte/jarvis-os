## Dependency note
The build environment has no outbound package index/network access. Existing installed versions of FastAPI, Uvicorn, Pydantic, HTTPX, scikit-learn, and related dependencies were used. `slowapi` is not installed in this environment, so the compatibility limiter was exercised instead. A normal connected deployment should install `api-gateway/requirements.txt` and use `slowapi` automatically.
